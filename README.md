# Rete node calculator

A visual-programming experiment (2021): drag number and operation nodes onto a canvas, connect them, and watch the result update. It's built on the Rete.js node editor with Vue rendering.

## Features
- Custom Rete components and a Vue `NumberControl`
- Connection, area (zoom and pan), context-menu, comment, history (undo/redo) and connection-mastery plugins
- Vue Router and Vuex scaffolding

## Tech stack
Vue 2 · Rete.js and plugins · Vuex · Vue Router · Bootstrap

## Run
```bash
npm install && npm run serve
```
